# Value Flow · VCAC 2026

เว็บแบบโต้ตอบ 7 หน้า อธิบายการส่งต่อคุณค่า (รายได้ · บุคลากร · ทรัพย์สินทางปัญญา · กิจกรรม) ของแผนที่ต่อยอดปาฐกถา VCAC 2026
เป็นไฟล์ static ล้วน (HTML + CSS + JavaScript) ไม่ต้อง build ไม่ต้องติดตั้งอะไร และไม่พึ่งบริการภายนอก (ฟอนต์อยู่ในโฟลเดอร์)

## หน้าทั้งหมด
| ไฟล์ | เนื้อหา |
| --- | --- |
| `index.html` | ภาพรวมห่วงโซ่ 5 ขั้น สลับมุมมองได้ |
| `players.html` | เครือข่ายผู้เล่นและทิศทางการส่งต่อคุณค่า |
| `revenue.html` | ช่องทางรายได้และวงจรแบ่งปัน 30–40% (ปรับตัวเลขได้) |
| `talent.html` | พีระมิด 3 ระดับ เรดาร์ทักษะ เส้นทางบุคลากร |
| `ip.html` | วงโคจร IP, แข่งความเร็วจดสิทธิ์, รูปแบบไลเซนส์ |
| `events.html` | วงล้อและไทม์ไลน์ของ 10 กิจกรรม |
| `roadmap.html` | แผนที่นำทาง 2569–2573 กดเล่นได้ |

## ดูในเครื่อง
เปิด `index.html` ได้เลย หรือรันเซิร์ฟเวอร์ชั่วคราว: `python3 -m http.server 8000` แล้วเปิด http://localhost:8000

## โฮสต์บน GitHub Pages
1. สร้าง repository แล้ว push ทุกไฟล์ในโฟลเดอร์นี้ขึ้นไป (ให้ `index.html` อยู่ที่ root)
2. Settings → Pages → Source: *Deploy from a branch* → เลือก branch `main` และโฟลเดอร์ `/ (root)`
3. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<username>.github.io/<repo>/`

ลิงก์ในเว็บเป็น relative ทั้งหมด จึงใช้ได้ทั้งแบบ project page (`/repo/`) และโดเมนของตัวเอง

## โฮสต์บน Vercel
- ผ่านเว็บ: Add New → Project → เลือก repository → Framework Preset: **Other** → ไม่ต้องใส่ Build Command → Deploy
- หรือใช้ CLI: `npm i -g vercel` แล้วรัน `vercel` ในโฟลเดอร์นี้ (`vercel --prod` เมื่อพร้อมขึ้นจริง)
- ไฟล์ `vercel.json` เปิด clean URLs ไว้ ทำให้เข้า `/revenue` ได้โดยไม่ต้องมี `.html`

## แก้เนื้อหา สี และฟอนต์
- เนื้อหา ตัวเลข รายชื่อ และเส้นทางทั้งหมด: `assets/js/data.js` (แก้ที่เดียว ทุกหน้าอัปเดตตาม)
- สีและฟอนต์: `assets/css/tokens.css` (ตัวแปร `--navy --blue --green --red` และ `--font`)
- โค้ดของแต่ละหน้า: `assets/js/pages/*.js` และ `assets/css/<หน้า>.css`
- ฟอนต์ Noto Sans Thai อยู่ใน `assets/fonts/` (สัญญาอนุญาต SIL Open Font License)
